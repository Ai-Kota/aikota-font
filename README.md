# aikota-font · 路线 B：纯自研骨架引擎（自有 IP 字库）

> 目标：一套**轮廓由本引擎规则生成**的中文字库（aikota 爱成 B 版），
> 不依赖 Arphic/A 路线的现成笔顺数据，字形版权归引擎作者。

## 与 A 路线（aikota v0.2.0）的边界

| | A 路线（已交付 v0.2.0） | B 路线（本目录） |
|---|---|---|
| 轮廓来源 | Arphic 1999 楷体笔顺数据（ARPHIC PL，衍生） | 本引擎骨架+笔形算法生成（自有） |
| 商业 | 免费使用/分发，不可卖字体文件 | 可授权/收费（字体厂商模式） |
| 现状 | GB2312 全量 6763 字 + 3 字重，已接入 AimlyVideo | Phase 1 起步 |

## 引擎架构（纯自研骨架）

```
码点 U+XXXX
  → 结构解析: 拆成 部首 + 摆位 (左/右/上/下/包围)
  → 部首骨架: 每个部首 = 参数化笔画序列 (横竖撇捺点折钩 + 起点/长度/角度)
  → 笔画指令: 每笔 { 类型, 起(x,y), 向量(dx,dy), 宽度, 笔锋 }
  → 笔形展开: 指令 → 闭合多边形 (起收笔宽窄按 taper 规则)
  → TTF: fontTools 写表 (复用 A 路线的 hinting/prep/质检流水线)
```

IP 判定要点（见 docs/2026-09-17-cjk-font-foundry-plan.md §B）：
- 汉字结构本身是公共知识（部件组合、笔顺规则）→ 不产生版权
- **轮廓的具体形状**（笔形算法输出：粗细曲线、笔锋角度、弧度）= 版权表达 → 归引擎作者
- 证据链：引擎源码 + 参数迭代记录 + 每个 commit，本仓 git 历史

## 下一步开工前需要补的东西

1. **部首骨架库**：214 康熙部首 + 常见偏旁（如 氵 礻 衤 艹 饣 贝 走 身...）的
   参数化笔画定义。这是最大的一块，先覆盖 100 高频字用到的部首（约 40-60 个）。
2. **摆位规则**：左右/上下/包围 结构的坐标分配公式（基于 1000upm 网格 + 部首宽高比）。
3. **笔形参数**：横竖粗细、撇捺 taper、点顿角度（全局可调，驱动多风格）。
